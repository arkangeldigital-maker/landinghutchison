Configurar acceso

Esto se hace una sola vez por usuario. El token de GitHub se guarda cifrado con la contraseña en admin/acceso.json: sin la contraseña no se puede leer. Usa una contraseña larga (12+ caracteres).

  1. Entra a GitHub → Fine-grained token nuevo con la cuenta dueña del repositorio.
  2. Repository access: «Only select repositories» → landinghutchison.
  3. Permissions → Repository permissions → Contents: «Read and write». Nada más.
  4. Elige la vigencia más larga que te deje, genera el token y pégalo abajo.

Si el usuario ya existe, se reemplaza (sirve para cambiar la contraseña o renovar el token).

Volver a entrar

Cómo funciona: prepara los cambios (XML y fotos) y pulsa Publicar cambios. Todo se guarda junto y queda en el sitio al momento.y el sitio se actualiza solo en 1 o 2 minutos. Solo se aceptan fotos JPG/JPEG; se reducen y se guardan como .jpg (portada hasta 1920 px de ancho, empresas hasta 1280 px) y se numeran 1, 2, 3… en el orden que ves.

Documentos (docs/)

Brochures y otros PDF. Aquí ves los que hay en el sitio: ábrelos con un clic o quítalos con el bote de basura. Después, en el editor, el campo de link de Brochure o Expansión los ofrece en una lista (o puedes escribir un link externo).

Solo PDF, hasta 60 MB. Los nombres se limpian (sin acentos ni espacios). Si ya existe uno con el mismo nombre, se reemplaza.
